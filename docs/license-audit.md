# Dependency and license audit status

Status: **open; not legal clearance for redistribution.** This workpaper records the repository inventory checked on **October 27, 2026**. It separates machine-readable lock metadata from actual license review; a package's declared license field or a successful build does not by itself establish compatibility.

The fresh `scripts/generate_dependency_inventory.py --repo-root .` inventory on October 27, 2026 contains 665 components across 9 manifests. Its 231 `missing_declared_license_metadata` entries mean **license metadata was not collected**, not that those components are unlicensed. Inventory v2 breaks the missing declarations down as 77 Go module records and 154 Python requirement records; it does not infer licenses. It reports 31 `unresolved_versions` in flexible optional-extra source declarations; `python/uv.lock` resolves those dependencies for locked installs. All 434 npm lock entries have a nonempty declared license field. Every inventory entry still has `license_review_status=unreviewed`, and `release_clearance=false`.

Uncollected license metadata by source manifest: `containers/engineering/build-requirements.lock` (pypi): 3, `containers/engineering/requirements-linux-x86_64-py312.lock` (pypi): 120, `go.mod` (golang): 77, `python/pyproject.toml` (pypi): 31.

## Repeatable dependency inventory

Run `python scripts/generate_dependency_inventory.py --repo-root .` to print the inventory, or add `--output <new-file>` to write a JSON file. The versioned `threadforge.dependency-inventory.v2` contract records hashes for its input manifests and entries for the resolved Go module graph, both npm lockfiles, the Engineering runtime/build Python locks, and each flexible Python optional-extra declaration. The separate `python/uv.lock` is enforced by CI with `uv lock --check` and `uv sync --locked`; inventory v2 does not yet expand its transitive/platform-specific records. V2 adds deterministic missing-license-metadata counts by ecosystem and source manifest, without inferring licenses. npm integrity values, Go module sums, and Python wheel hashes are preserved; registry URLs and machine-local paths are omitted. The v1 schema remains available for earlier inventory payloads.

The report marks every component `license_review_status=unreviewed`; missing license metadata stays missing, automatic license inference is false, the source declarations retain flexible ranges even though CI uses the committed lock, and `release_clearance` is always false. The detailed gap breakdown is triage evidence only, not a complete release-artifact SBOM, license classification, or legal approval. `test.ps1` generates it only under a unique temporary path.

## Release gate

Before distribution, generate a complete transitive SBOM/license inventory for the exact release artifacts and supported platform/runtime combinations; reconcile it against retained notices; review the Mancode-derived contract boundary and every dataset/evaluator; and obtain independent legal approval. Keep the all-or-nothing cutover closed until those checks, full feature parity, migration reconciliation, and held-out efficacy gates pass.
